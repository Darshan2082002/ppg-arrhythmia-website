Arrhythmia Detection Using PPG

An Edge-AI framework utilizing 1D-CNN and TCN architectures on the ESP32-S3 for real-time multi-class classification and motion artifact compensation.

System Architecture View Live Demo

Project Overview

Continuous, non-invasive cardiac monitoring built for the edge.

📊

Clinical Datasets

Trained on the MIMIC-III-Ext-PPG database. Motion artifacts are dynamically removed using a Normalized Least Mean Squares (NLMS) adaptive filter.

MIMIC-IV Data → MIMIC-III Waveforms →
⚡

Edge Optimization

Leverages Post-Training Quantization (PTQ) to convert FP32 weights to INT8, allowing the deep learning models to execute within the 512KB SRAM of the ESP32-S3.

🧠

TinyML Framework

Utilizes TensorFlow Lite for Microcontrollers (TFLM) to execute 1D-CNN and TCN inferences for multi-class arrhythmia detection (NSR, AFib, PVC).

System Architecture

01

Data Acquisition (Core 0)

FreeRTOS task polling the MAX30102 PPG and MPU6050 IMU sensors via a 400kHz Fast Mode I2C bus.

02

Signal Conditioning (Core 1)

4th-order Butterworth bandpass filter (0.5–8.0 Hz) and NLMS adaptive filtering suppress baseline wander and kinematic noise.

03

Edge Inference (Core 1)

The TFLM operations resolver processes 5-second overlapping data windows through the quantized 1D-CNN.

04

Diagnostic Telemetry

Argmax function yields the arrhythmia class, outputting to a local 0.96-inch SSD1306 OLED frame buffer.

Hardware Stack

Edge Processing with ESP32-S3

The system utilizes the Xtensa® dual-core 32-bit LX7 microprocessor. Its built-in vector instructions accelerate the MAC operations for the neural network, allowing sub-second inference.

  • Sensors: MAX30102 Optical PPG & MPU6050 6-Axis IMU
  • Display: 0.96-inch SSD1306 OLED (128x64px)
  • Firmware: Embedded C++ utilizing FreeRTOS for thread-safe asynchronous task handling
